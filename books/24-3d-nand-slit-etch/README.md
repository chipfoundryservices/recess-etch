# Book 24 — 3D NAND Slit Etch

16 chapters in four parts, Appendices A–G, glossary and index (~9,900 words).

- Read: `build/out/book24-3d-nand-slit-etch.html` or `.epub`
- Rebuild: `python3 build/build.py` (needs `markdown`)
- Re-run the transport simulation: `cd sim && python3 transport_mc.py` (needs `numpy`, ~1.5 min)

Transport numbers (Ch. 4, App. B) are computed by `sim/transport_mc.py`; process values elsewhere are illustrative.
